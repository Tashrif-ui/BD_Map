## 0. Project Rules (Mandatory)

### Rule 1 — 100% Free Stack
Everything must be built, hosted and run at **zero cost**.

| Need | Free solution |
|---|---|
| Hosting | **Cloudflare Pages** (free plan: unlimited static requests & bandwidth, 500 builds/month) |
| Domain | Free `*.pages.dev` subdomain (custom domain optional, only if the owner buys one) |
| Source code | GitHub public repository (free) |
| CI / build | Cloudflare Pages Git integration (builds on every push to `main`) |
| Map library | Leaflet (open source, BSD-2) |
| Base map tiles | **None by default** — boundaries are drawn from GeoJSON on a themed background (no API key, no cost, no English tile labels clashing with Bangla). CARTO basemaps now require an API key, so they are not used. |
| Data processing | Node.js scripts; Python + GeoPandas / mapshaper (all free) |
| Search | Client-side search (e.g. Fuse.js) — no paid search service |
| Backend / database | **None.** The site is fully static; all data ships as JSON/GeoJSON files |

Constraints that come with the free plan:
- **Cloudflare Pages max file size is 25 MiB per file** and 20,000 files per deployment. Large GeoJSON (upazila, union, constituency) must be **simplified** (e.g. with mapshaper) and/or **split per district/division** and loaded on demand.
- Do not add any paid API, paid tile provider, or service that needs a credit card.

### Rule 3 — Licensing & Anti-Copy Protection
Be honest about what is possible: anything published on the public web can technically be copied. The goal is to make **legal ownership clear** and **removal of credit a license violation**.

- **Code** (React components, scripts, styles): **CC BY-NC-SA 4.0**, `Copyright (c) 2026 Tashrif Alam`. Anyone reusing the code must credit Tashrif Alam, **may not use it commercially**, and must share changes under the same license.
  - Note: because of the non-commercial clause, the code is "source-available", not OSI "open source". This is an intentional owner decision.
- **Project-created content** (curated data files, Bangla/English name tables, descriptions, map styling, documentation): **CC BY-NC-SA 4.0** — anyone reusing it **must credit Tashrif Alam**, **may not use it commercially**, and must share any adaptations under the same license.
  - Decision (owner, 2026-10-15): BD-Map is a **non-commercial, knowledge/educational project**. No ads, paid features, or selling of data. **No part of the project — code or content — may be used commercially by anyone.**
- **Third-party data** (Election Commission gazettes, GeoJSON repositories, OpenStreetMap, etc.) is **NOT owned by the project**. It keeps its original license, must be credited to its original source, and must **never** be relabeled as the owner's work. The owner's copyright covers only the owner's own processing, curation, code and presentation.
- Keep a `DATA_SOURCES.md` (or a sources section) listing each dataset, its URL, license, and date retrieved.
- Extra (free) measures:
  - Fingerprint data: keep a private record of a few unique, harmless details (e.g. ID format, ordering, coordinate precision) to help prove copying.
  - Git history acts as a public timestamped proof of authorship.
  - If copying without credit is found, use GitHub's free DMCA takedown process.

### Rule 4 — Data Accuracy
- Never invent names, seat numbers, or boundaries. Missing data stays missing and is marked as such.
- Every dataset records its `source` and `last_verified` date.
- Administrative boundaries and parliamentary constituency boundaries are stored **separately**.
- Upazila and thana (police station) boundaries are stored as **separate datasets**.

### Rule 5 — Bilingual
All user-facing names and UI text are available in **Bangla and English**, switchable at any time via the language switcher (see [Section 2.F](#f-language-switcher-bangla--english)).

### Rule 6 — Light & Dark Mode
The whole site (UI **and** map) supports **light and dark themes** via a theme toggle (see [Section 2.G](#g-light--dark-mode)).

## 1. Project Overview

**Project Name:** BD-Map

**Short Description:**
An interactive map of Bangladesh featuring 8 divisions, 64 districts, upazilas, thanas, and parliamentary constituencies.

**Project Goal:**
Build a comprehensive, interactive map of Bangladesh that contains administrative boundaries and geographical information for all divisions, districts, upazilas, thanas, unions, and parliamentary constituencies. Users should be able to explore the map, search for locations, view administrative details, and identify parliamentary seat numbers and boundaries.

## 2. Main Features

### A. Bangladesh Administrative Map
- Complete map of Bangladesh.
- All 8 administrative divisions.
- All 64 districts.
- Interactive map with zoom and pan functionality.
- Clickable divisions and districts.
- Search by Bangla or English names.

### B. Administrative Information
- Division names.
- District names.
- Upazila lists under each district.
- Thana and police station information.
- Union information.
- Municipality and city corporation information, where available.
- Administrative hierarchy showing which areas belong to which divisions and districts.
- Bangla and English names for locations.

### C. Parliamentary Constituencies
- All 300 general parliamentary constituencies.
- Parliamentary seat numbers and names.
- Districts associated with each constituency.
- Upazilas and other areas included in each constituency.
- Electoral constituency boundaries on the map.
- Information based on the latest verified Bangladesh Election Commission gazette.
- Historical boundary changes, where reliable data is available.

**Important:** Administrative boundaries and parliamentary constituency boundaries are not always identical. Parliamentary constituencies must have their own verified boundary data.

Also, upazilas and police station jurisdictions do not always follow the same boundaries. They should be stored as separate administrative datasets.

### D. Interactive Map Features
- Zoom in and zoom out.
- Pan around the map.
- Click a division or district to view its details.
- Select a district to explore its upazilas.
- Search for divisions, districts, upazilas, thanas, unions, and constituencies.
- Toggle different map layers on and off.
- Display parliamentary constituency numbers on the map.
- View detailed information in a sidebar or popup.
- Show data sources and last verification dates.
- Show owner attribution in the map's attribution control (Rule 2).

### E. Map Layers
Users should be able to toggle these layers:

1. Divisions
2. Districts
3. Upazilas
4. Thanas / Police Stations
5. Unions
6. Parliamentary Constituencies

### F. Language Switcher (Bangla / English)
- A switcher in the header shows two options **with flags**:
  - 🇧🇩 **বাংলা** — Bangladesh flag
  - 🇺🇸 **English** — US flag
- Flags must be **inline SVG files** (`src/assets/flags/bd.svg`, `us.svg`), **not emoji** — Windows does not render flag emoji (it shows the letters "BD"/"US" instead).
- Each option shows the flag **plus the language name as text**, so it stays clear and accessible (flags alone represent countries, not languages).
- Switching language changes instantly, without page reload:
  - All UI text (header, buttons, layer names, sidebar, footer, About page).
  - Location names on the map and in popups (`name_bn` / `name_en`).
  - Numbers in Bangla digits when Bangla is active (e.g. seat `১`, not `1`).
  - Search accepts both Bangla and English input regardless of the active language.
- Default language: **Bangla**; if the browser language is English, start in English.
- The chosen language is saved in `localStorage` (key `bdmap-lang`) and restored on next visit.
- `<html lang="bn">` / `<html lang="en">` is updated on switch.
- UI strings live in translation files: `src/i18n/bn.json` and `src/i18n/en.json` (no hard-coded text in components).
- Bangla font: **Noto Sans Bengali** or **Hind Siliguri** (free, Google Fonts).
- Implementation: small custom React context (`LanguageContext`) — no paid or heavy i18n service needed.

### G. Light & Dark Mode
- A theme toggle button (☀️ / 🌙 icon) in the header, next to the language switcher.
- Three behaviours:
  1. **First visit:** follow the system/browser setting (`prefers-color-scheme`).
  2. **User toggles:** the chosen theme is saved in `localStorage` (key `bdmap-theme`) and used on later visits.
  3. No flash of the wrong theme on load (theme is applied by a tiny inline script in `index.html` before React renders).
- Colors are defined as **CSS variables** on `:root` and overridden under `[data-theme="dark"]` — no hard-coded colors in components.
- The **map itself** also switches theme:
  - Default: **no base tiles** — the map is drawn from GeoJSON only, on a theme-colored background (light / dark), with division fills and boundary lines styled per theme.
  - Optional later: a free, key-less tile source (e.g. OpenStreetMap standard tiles, respecting the OSM tile usage policy) for light mode only.
  - Boundary line colors, fills, labels and popups have separate light and dark styles with good contrast.
- Both themes must meet readable contrast (WCAG AA) for text and map labels.
- The owner attribution (Rule 2) must be clearly visible in both themes.

## 5. Data Sources

Use reliable, verifiable sources for administrative and electoral data.

1. Bangladesh Election Commission — electoral constituency boundaries and gazettes:
   https://ecs.gov.bd/page/gazette-related-to-electoral-areas?lang=en
2. Bangladesh GeoJSON repository:
   https://github.com/ifahimreza/bangladesh-geojson
3. Bangladesh GeoJSON and shapefile resources:
   https://github.com/yasserius/bangladesh_geojson_shapefile

These are starting points, not a guarantee that every dataset is complete or current. Verify the data, its geographic accuracy, update date, and **license** before using it, and credit each source (Rule 3).

## 6. Data Format

JSON for administrative information, GeoJSON for boundaries. Every project-created file is wrapped with the `meta` block from Rule 2.

Example district record:

```json
{
  "id": "district-example",
  "name_en": "Example District",
  "name_bn": "উদাহরণ জেলা",
  "division_id": "division-example",
  "upazila_ids": [],
  "source": "Verified official source",
  "last_verified": "YYYY-MM-DD"
}
```

Example parliamentary constituency record:

```json
{
  "seat_number": 1,
  "name_en": "Example-1",
  "name_bn": "উদাহরণ-১",
  "district_ids": [],
  "upazila_ids": [],
  "boundary_source": "Bangladesh Election Commission",
  "last_verified": "YYYY-MM-DD"
}
```

These examples are illustrative templates, not actual official records.

## 7. Data Accuracy and Validation

- Verify the total of 8 divisions and 64 districts.
- Check administrative parent-child relationships.
- Verify upazila and thana lists against appropriate sources.
- Use the latest applicable official electoral gazette for constituency boundaries.
- Keep administrative boundaries and electoral boundaries separate.
- Record the source and verification date for each dataset.
- Avoid inventing missing names, seat numbers, or boundaries.
- Respect the licenses and attribution requirements of all external datasets.
- Validate GeoJSON geometry and ensure boundaries align correctly on the map.
- `validate-data.js` also checks that every project-created data file contains `meta.author` (Rule 2) and that no file exceeds 25 MiB (Rule 1).

## 9. Deployment — Cloudflare Pages (Free)

1. Push the repo to GitHub.
2. Cloudflare dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → select `BD-Map`.
3. Build settings:
   - Framework preset: **Vite** (or React (Vite))
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Environment variable: `NODE_VERSION=22`
4. Deploy → site is live at `https://bd-map.pages.dev` (or the next available name).
5. Every push to `main` redeploys automatically; pull requests get free preview URLs.
6. Add `public/_headers` to cache large GeoJSON files:
   ```
   /data/*
     Cache-Control: public, max-age=86400
   ```

## 10. Development Roadmap

- **Phase 1:** Create the GitHub repository, README, LICENSE files, and set the owner name (Rules 2–3).
- **Phase 2:** Collect and validate Bangladesh's administrative datasets; document sources and licenses.
- **Phase 3:** Build the initial interactive map with divisions and districts; add footer + map attribution with owner name; language switcher (বাংলা/English with flags) and light/dark mode; first deploy to Cloudflare Pages.
- **Phase 4:** Add upazilas, thanas, and unions (simplified and split for the 25 MiB limit).
- **Phase 5:** Integrate verified parliamentary constituency boundaries and seat numbers.
- **Phase 6:** Add search, filters, map layers, and detail panels.
- **Phase 7:** Validate geographical accuracy, finalize source documentation, About page, and production deploy.

### Status (2026-10-15)

Phases 1–6 are implemented and Phase 7 is complete except the first deploy, which needs the owner's Cloudflare account. Open data gaps (city-corporation ward boundaries, newer unions/thanas, some Bangla names) are tracked in [TODO.md](TODO.md).

## 11. Final Vision

BD-Map will be an open, bilingual, interactive geographical resource for Bangladesh, created and maintained by **Tashrif Alam**. It will combine administrative information and parliamentary constituency boundaries in one place, allowing users to explore the country from the division level down to smaller administrative areas and electoral constituencies.

The priority is to build the project incrementally, keep the data verifiable, keep it free to host and use, credit the owner on everything, and make the map useful for students, developers, researchers, journalists, and the general public.
